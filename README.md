# InAmigos Foundation - Awareness & Landing Page

A modern, responsive landing page built to showcase the mission, flagship projects, and social impact of the **InAmigos Foundation**—a Section 8 registered NGO dedicated to building a compassionate, equitable, and sustainable India.

This project serves as an awareness platform highlighting their key initiatives in education, environment, animal welfare, and community development.


## ✨ Features

* **Responsive Design:** Optimized for seamless viewing across desktops, tablets, and mobile viewports.
* **Flagship Project Spotlights:** Dedicated sections detailing the NGO's 6 active initiatives:
    * **Project SEVA:** Food & Clothing Distribution
    * **Project BACHPANSHALA:** Digital Literacy & Academic Support
    * **Project UDAAN:** Women Empowerment & Skill Development
    * **Project JEEV:** Animal Welfare & Daily Feeding Drives
    * **Project PRAKRITI:** Environmental Sustainability & Tree Plantation
    * **Project VIKAS:** Youth Internship Programs
* **Impact Metrics Counters:** Highlighting real-world statistics (e.g., 50,000+ meals distributed, 20,000+ saplings planted).
* **Call-to-Actions (CTA):** Clear user journeys for prospective volunteers, donors, and interns.
